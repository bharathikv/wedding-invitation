# Thangaraj & Vikitha — Wedding Invitation (React + Vite)

    npm install
    npm run dev        # local preview (also on your phone via the Network URL)
    npm run build      # production build in /dist  → upload to Netlify / Vercel

## What's inside
- `src/data/wedding.js`  – names, dates, venue, family, phone numbers (edit here)
- `src/data/content.js`  – every Tamil / English sentence
- `src/components/Gods.jsx` – Ganesha, Lakshmi, Annamalaiyar, Murugan artwork, diya, kalasam, temple skyline
- `src/components/TouchFx.jsx` – tap / swipe petals & sparkles, 3D tilt cards
- `src/components/Splash.jsx` – temple-door intro with language choice
- `src/effects.css` – temple theme + animations

## Use your own God images (optional)
Put PNG files in `public/gods/` named `ganesha.png`, `lakshmi.png`, `shiva.png`, `murugan.png`.
They automatically replace the built-in drawings. Missing file = built-in art is used.
